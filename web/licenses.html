WebKit + WASM test — licences and source

This test uses WebkitWasm, WebKit and the separately loaded Wisp 0.5.0 library. Wisp is Copyright (C) 2024 Mercury Workshop, under LGPL-3.0-or-later. The small WebSocket-constant compatibility modification is dated in its readable source.

Source and build instructions · Wisp source

Users may modify the LGPL library and debug those modifications. The standalone test loads vendor/wisp-client.js as a separate file; an interface-compatible modified client can replace it.
